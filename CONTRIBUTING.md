# Як робити зміни

Спільні правила для репозиторіїв BurCob.

Гілка `main` захищена. Зміни потрапляють у неї лише через pull request.

## Гілки

Створюйте гілку від актуального `main`. Назва латиницею, слова через дефіс:

- `feat/коротка-назва` — нова можливість
- `fix/коротка-назва` — виправлення
- `chore/коротка-назва` — супровід

## Як відкрити pull request

1. Оновіть `main` і створіть від нього гілку.
2. Зробіть зміни невеликими комітами.
3. Відкрийте pull request у `main` і заповніть шаблон.
4. Дочекайтеся рев’ю. Після схвалення зміни зливають у `main`.

## Коміти

Формат: `тип: що зроблено`. Опис українською: «додати», «виправити», не «додав». Перший рядок — до 72 символів.

Типи: `feat` (можливість), `fix` (виправлення), `chore` (супровід), `docs`, `refactor`, `test`.

- `feat: додати фільтр за виконавцем`
- `fix: виправити збереження картки`
- `chore: оновити залежності`

Якщо з першого рядка не ясно навіщо, допишіть пояснення нижче.
